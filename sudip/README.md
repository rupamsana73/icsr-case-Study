# ICSR Case Intake and Validation — Submission Package

This package contains:
1. `ICSR_Case_Report.csv` — structured ICSR-style case form.
2. `Chronology.txt` — medication/event chronology.
3. `Completeness_Checklist.txt` — minimum-element and missing-information validation.
4. `index.html` — a single-page, view-only submission page.
5. `ICSR_Case_Report.pdf` — printable report.

IMPORTANT:
The screenshots provided for the task show that an "ICSR case-intake sample · CSV" is a required dataset resource, but that CSV itself was not included in the uploaded files available to me. Therefore, the case in this package is explicitly a FICTIONAL, DE-IDENTIFIED TRAINING CASE created to satisfy the displayed task structure. It should not be represented as an extracted case from the missing dataset.

Official reference used for the minimum ICSR elements:
https://database.ich.org/sites/default/files/ICH_E2D%28R1%29_Step4_FinalGuideline_2025_0819.pdf

The task asks for one public or view-only link. Upload `index.html` (and the supporting files) to a public static host such as GitHub Pages, or place the folder in a view-only repository/project page. The resulting public/view-only URL can then be submitted.
